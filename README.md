# V2V-COMMUNICATION-SIMULATION-IN-QNX-momentics
Real-time Vehicle-to-Vehicle (V2V) communication system simulated using QNX RTOS, QEMU, and Virtual Ethernet. Implements UDP-based communication, dynamic Wi-Fi/LoRa protocol switching, packet loss simulation, GPS distance calculation, and collision warning detection with SCHED_FIFO real-time scheduling.
